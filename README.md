Interactive web prototype for **TRAPPED**, an immersive analog-collage installation by Briana Ratterman.

Live site: *(add your GitHub Pages link here once it's on)*

## How this repo works
- `index.html` is the whole piece — styles, script, and images are all inside this one file.
- To update: replace `index.html` with the new version and commit. The live site refreshes within a minute or two.
- Every commit is saved, so any earlier version can be recovered from the History view.
